# Security Policy

Please report suspected vulnerabilities privately. Do not open a public issue for security-sensitive findings.

Include:

- A clear description of the issue.
- Steps to reproduce when safe.
- Affected role, endpoint, workflow, or deployment surface.
- Any evidence needed to validate impact.

Avoid including real credentials, live tokens, private keys, production data, or personally identifiable information in the report. A maintainer should acknowledge the report privately, assess severity, and coordinate a fix before public disclosure.
